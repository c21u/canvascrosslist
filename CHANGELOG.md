# AdminLTI Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.2] - 2019-06-19
### Fixed
- Build process refinements.
- Terms list (i.e. Full Imports view) no longer includes manually-created terms.

## [0.1.1] - 2019-06-14
### Changed
- Build the docker image in two stages.

## [0.1.0] - 2019-04-22
### Added
- Added Buildspec for CodeBuild.
- Added depency on caccl-api Canvas request library.
- Isolate section now sends updates to BuzzAPI.

### Changed
- Dependencies upgraded.
- Made client code bundling more efficient.
- Refactored server files and config.
- Refactored isolate section handler.
- Updated Dockerfile.

### Removed
- Deleted unused files.
